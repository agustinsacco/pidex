# specs/archive

Implementation plans whose work has landed, plus the completed early phases of
the build tracker. Kept rather than deleted: the plans record _why_ things were
built the way they were, and several carry an **Outcome** section listing
deviations that the code still reflects.

Nothing here is a live contract. For current state see
[../TRACKER.md](../TRACKER.md); for the domain specs that still describe how
pidex is supposed to behave, see the numbered files in [..](..).
