# Reference screenshots

Claude Desktop "Code" reference captures. The following files are available in this directory:

- `home-light.png` — greeting screen, stat tiles, heatmap (light theme, empty session list)
- `home-populated.png` — greeting screen, stat tiles, heatmap with populated session sidebar and composer input
- `chat-tool-calls.png` — active conversation, streaming chat, collapsed tool cards with chevrons
- `chat-file-chips.png` — file preview chips and inline code block directory tree rendering
- `chat-full-width.png` — chat view with collapsed sidebar (full-width view)
- `composer-plus-menu.png` — composer `+` button autocomplete dropdown menu (files, folders, slash commands, plugins)
- `composer-model-picker.png` — composer model selector dropdown and fast mode toggle switch
- `profile-menu.png` — user profile dropdown menu at bottom-left (Settings, Language, Account)
- `sidebar-sessions.png` — sidebar session list with right-click context menu (Open PR, Pin, Rename, Fork, Delete)
- `terminal-pane.png` — side terminal panel with shell output and header controls
- `artifact-panel.png` — three-panel layout showing the Artifacts viewer on the right
- `files-diff-pane.png` — three-panel layout showing Files Changed and Monaco split diff viewer on the right
- `settings.png` — main Settings window (General & Claude Code appearance settings with theme diff preview)
- `settings-connectors.png` — Settings window showing the Connectors tab and status list

The build agent must Read these as images before each UI-heavy phase (P1, P2, P3, P4, P5, P6).
